# Portfólio Wesley Costa Films

Site de uma página: abra o index.html no navegador para ver.

- index.html: o site inteiro (textos, cores, sliders)
- videos/: Reels comprimidos para a web
- capas/: capa de cada vídeo

Para editar, abra esta pasta no Claude Code e peça as mudanças.
Para colocar no ar, dá para usar Netlify, Vercel ou GitHub Pages.
